# seomun-admin

Admin frontend for Seomun.

## Stack

- Vite
- React
- Tailwind CSS v4
- shadcn/ui
- TanStack Router
- TanStack Query
- Zustand
- TypeScript

## Development

```bash
yarn
yarn dev
yarn build
yarn lint
yarn check-types
```
